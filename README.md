Internship

- Task: Day 11 – Basic Data Sorting & Filtering
Project Overview
This task uses the Global Superstore dataset to practise sorting, filtering, and basic business analysis in Microsoft Excel. The original Orders worksheet was preserved, and a separate Day11_Sorting_Filtering worksheet was used for analysis. Answers were recorded in Day11_Answers.
Dataset
- File: GlobalSuperstore.xlsx
- Worksheet: Orders
- Analysis range: A1:W51291 (header plus data rows)
- Fields used: Region, Category, Segment, Product Name, Sales, and Profit
Work Completed
1. Copied the complete dataset into a separate analysis worksheet while preserving the original data.
2. Sorted Sales from largest to smallest.
3. Applied multiple filters:
   - Category = Furniture
   - Region = South
   - Sales greater than 1,000
4. Created PivotTables to summarize Sales by Region, Category, and Segment.
5. Recorded the five business-question answers in Day11_Answers.

Total Sales check: 12,642,501.91
Tools and Features
- Microsoft Excel
- Sort Largest to Smallest
- AutoFilter and multiple filter criteria
- PivotTables (Sum of Sales)
- Worksheet formatting
Key Learnings
- Sorting helps rank records and identify high or low values.
- Filters display only records that meet selected conditions without deleting the underlying data.
- Multiple filters can be combined to answer more specific questions.
- PivotTables summarize large datasets by categories such as Region, Category, and Segment.
- Preserving raw data makes analysis easier to verify and reproduce.
